## 주요 기능
1. **로그인**: 전화번호 기반 Firebase 인증, 자동 로그인
2. **운동 일지**: 세트/중량/횟수 기록, 1RM 강도 10단계, 바벨 서포터
3. **루틴 추천**: 그리디+위상정렬로 시간 내 최적 루틴 자동 생성
4. **기구 예약**: 실시간 대기열(Firebase), 큐 스케줄링
5. **플레이리스트**: 목표별 유튜브 플레이리스트
6. **성장 분석**: 주간 볼륨 추세, Top5 운동(힙 정렬), 부위별 비중
7. **식단**: 내장 식품 DB 검색, 탄단지 분석, 목표 칼로리 설정
8. **프로필**: 신체 정보(키/체중/체지방/골격근/BMI), 변화 그래프
