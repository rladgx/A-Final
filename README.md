## 주요 기능 (웹 앱)
1. **로그인** — 전화번호 기반 Firebase 인증
2. **운동 일지** — 세트/중량/횟수, 1RM 강도 분석, 바벨 서포터, **루틴 공유**
3. **루틴 추천** — 그리디 + 위상 정렬로 시간 내 최적 루틴 자동 생성
4. **기구 예약** — Firebase 실시간 대기열, **QR 스캔 예약**, **바텀시트 팝업**, **진동 알림**
5. **운동 찾기** — BST + DFS + 이진 탐색, **초성 자동완성**
6. **식단** — 식품 DB 검색, 탄단지 분석, 목표 칼로리, **칼로리 소모 계산**
7. **성장 분석** — 주간 볼륨, Top5(Max-Heap), 부위별 비중
8. **프로필** — 신체 정보, BMI, 변화 그래프
