## 적용 알고리즘 & 자료구조

| 모듈 | 자료구조 | 알고리즘 |
|------|---------|---------|
| 루틴 추천 | 그래프(인접리스트), 해시맵 | 위상 정렬(Kahn's), 그리디 |
| 기구 예약 | 큐(Queue), 힙(Max-Heap) | 큐 스케줄링(FIFO), 힙 정렬 |
| 운동 찾아보기 | BST, 배열 | DFS, 이진 탐색 |
| 운동 기록 분석 | 배열, 해시맵 | 힙 정렬(Top5 추출) |

## 주요 기능
1. **로그인**: 전화번호 기반 Firebase 인증
2. **운동 일지**: 세트/중량/횟수 기록, 1RM 강도 분석(10단계), 바벨 서포터
3. **루틴 추천**: 그리디+위상정렬로 시간 내 최적 루틴 자동 생성
4. **기구 예약**: 실시간 대기열(Firebase 연동), 큐 스케줄링
5. **플레이리스트**: 목표별 유튜브 플레이리스트 추천
6. **성장 분석**: 주간 볼륨 추세, Top5 운동, 부위별 비중
7. **식단**: 식품안전처 API 실시간 검색, 탄단지 분석
8. **프로필**: 신체 정보(키/체중/체지방/골격근) 추적, 변화 그래프
